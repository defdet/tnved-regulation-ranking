# Разметка для локальной проверки

В `dev_labels.jsonl` находится по одной выбранной регуляции для каждой из 120
деклараций.

Разметка получена с помощью Sonnet 5. Декларации были разделены на четыре части
по 30; для каждой части модель получила полный каталог из 360 регуляций с
добавленной иерархией ТН ВЭД. Результаты ранжирования при назначении меток не
использовались.

Поля записи:

- `declaration_id` — идентификатор декларации;
- `regulation_id` и `code` — выбранная регуляция и код ТН ВЭД;
- `runner_up` — ближайшая альтернатива;
- `confidence` — оценка уверенности, которую сообщила Sonnet 5 (`high`, `medium`
  или `low`);
- `evidence` — признак, по которому выбран код.

Распределение уверенности: 112 `high`, 6 `medium`, 2 `low`. Восемь записей с
`medium/low` следует считать сомнительными. Например, для D0081 год выпуска
автомобиля находится на границе двух возрастных интервалов, а точный месяц в
декларации отсутствует.

Структурная проверка: все 120 выбранных регуляций различны; в каждой
из 83 товарных позиций, представленных тремя кандидатами, выбрана ровно одна.
